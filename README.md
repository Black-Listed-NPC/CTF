## 🗂️ Repository structure

```
CTF/
├── README.md              ← you are here
└── SecLeaf/
    ├── README.md          ← event overview + list of challenges
    ├── _template/         ← copy this for every new challenge
    ├── Web/
    ├── Crypto/
    ├── Pwn/
    ├── Reversing/
    ├── Forensics/
    ├── OSINT/
    └── Misc/
```

Each challenge folder has:

- `README.md` — the writeup (challenge info, approach, solution, flag)
- `solve.py` / `exploit.py` — solve script (if any)
- `files/` — challenge files given by organisers (if allowed to share)
- `images/` — screenshots used in the writeup
